# Project Objective — MIX IT

Develop **MIX IT**, an original, professional and scalable Windows live
production and broadcast studio: multi-camera switching, audio mixing,
graphics, recording, streaming and broadcast automation in one application.

The capability target is comparable to established professional products
(such as vMix) while every part of MIX IT — source code, architecture,
interface, processing engines and identity — is original. No proprietary code
is copied, decompiled or reverse-engineered; only public standards, OS APIs,
open-source projects and legally licensed SDKs are used.

## Core objectives

1. Multi-camera switching and production with scalable inputs and configurable outputs.
2. Native video engine: HDMI/SDI capture, webcams, NDI, IP cameras (RTSP/SRT), files, screen capture.
3. Audio engine: EQ, dynamics, routing, buses, VST3 hosting.
4. Streaming: RTMP, RTMPS, SRT, HLS, multiple destinations.
5. Recording: program and ISO, multi-session.
6. Graphics and compositing: overlays, titles, lower thirds, keying, virtual sets.
7. Production tools: multiview, replay, macros, automation, PTZ, tally, external outputs.
8. Adaptive hardware detection and performance recommendations.
9. An original, customizable operator interface.
10. Free and Professional editions with a scalable licensing foundation.

## Principles

- A real product, not a demonstration: features exist only when they work.
- Core engine first; UI follows working engine capabilities.
- Real-time performance, low latency, accurate synchronization, efficient CPU/GPU use.
- Modular, documented, independently tested components that can grow without rewrites.

**Platform:** Windows 10/11 x64 · **Architecture:** C# (.NET 10, WPF) + native C++20 · **Strategy:** core engine first.
